MusicTheory

Music theory for .NET that spells every note correctly, from a single pitch to an analysed progression.

dotnet add package MusicTheory

Read the documentation

I

The note

A note is a letter, an accidental and an octave. Middle C is C4. Two notes are equal when all three match, so C♯4 and D♭4 are different notes that happen to sound the same.

Concert pitch is a parameter, not a constant. Orchestras tune higher, baroque ensembles lower.

II

The interval

Six semitones can be an augmented fourth or a diminished fifth. The letters decide, and the library counts letters. C up to F𝄪 is not a tritone: it is a doubly augmented fourth.

Intervals have a direction. E down to C is a descending major third, written the way music21 writes it.

Every one of the 3,669 spelled intervals between two octaves is checked against music21 in the test suite.

III

The scale

A scale is a set of intervals above a tonic. Built that way, F♯ major cannot come out with an F natural: its seventh degree is E♯.

IV

The chord

Read a lead sheet the way a pianist does. The symbol is parsed into a type and its tensions, then every tone is spelled from the root.

Every key is a place on one circle.

VI

Harmony

Put chords in a key and read them back as Roman numerals. The analysis works by pitch class, so a careless spelling on the lead sheet still lands on the right degree.

Or ask which key a progression is in. Am F C G starts and ends near A minor.
